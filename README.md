THIS IS PLAGARISM DETECTOR PROJECT

DESCRIPTION:- 

THIS IS A BASIC PROJECT WHERE WE ARE ANALYZING A HANDWRITTEN TEXT BASED ON IT'S SPELLING MISTAKES AND AI SIMILARITY 
IT CAN BE POTENTIALLY USED BY TEACHERS AND PROFESSIONALS TO HELP EVALUATION ,

ALTHOUGH CURRENTLY IT IS VERY IMPORTANT TO NOTE THAT NOWADAYS IT IS VIRTUALLY IMPOSSIBLE TO TELL 
THE DIFFERENCE BETWEEN HUMAN AND AI BECAUSE:-

 1. EVER EVOLVING LLMS LEARNING ON HUGE(ALMOST ALL) HUMAN CREATED DATA.
 2. MANY RESEARCHERS AT ANTHROPIC HAVE DETECTED AN EMOTION LIKE CLUSTERS IN THEIR MODEL THAT TRIGGERS DURING CERTAIN SITUATION
   https://www.bloomberry.ai/blog/anthropic-claude-functional-emotions-ai-writing

 3. AIS HAVE OFFICIALLY PASSE TURING TEST SIMPLY PUTTING IT IS ALMOST IMPOSSIBLE FOR A HUMAN TO TELL THE DIFFERENCE BETWEEN A HUMAN AND AI
   https://futurism.com/ai-model-turing-test

ALTHOUGH MANY MODELS CAN MIMIC DIFFERENT PERSONALITIES AND PROFESSIONS , OLD MODELS STILL STRUGGLE WITH THIS FEATURE.
REALISTICALLY THIS PROJECT CAN STILL BE USEFUL FOR EVALUATING SCHOOL CHILDREN  BECAUSE:-

1. A CHILD USING AI WILL TEND TO MAKE LESS SPELLING/GRAMMATICAL MISTAKES.
2. A CHILD NOT USING AI WILL SUFFER IN SPELLINGS AND GRAMMAR OFTEN.
3. 
SO THIS PROJECT CAN STILL BE HELPFUL FOR MIDDLE AND HIGH SCHOOL TEACHERS.




TECH USED :- HTML/CSS/JS(FRONTEND) , FLASK(BACKEND) , AMAZON_TEXTRACTOR(OCR)  , COPYLEAKS_APIS(FOR AI SIMILARITY DETECTION)

  PROCEDURE OF SETUP:-

   U NEED TO SAVE THE IMAGE IN YOUR GMAIL MAKE IT PUBLIC AND SUBMIT THE IMAGE_URL ON THE WEBSITE.
   
   INSTALL PYTHON 
  
   U NEED TO HAVE AN ACTIVE AWS ACCOUNT (SEE YOU TUBE) AND ACTIVATE TEXTRACT FEATURE THERE
   U NEED TO CREATE AN ACCESS KEY WITH ADMIN ROLE AND SAVE IT'S CREDENTIALS IN .env FILE
   U NEED TO CREATE A COPYLEAKS API KEY AND SAVE IT ALONG WITH YOUR GMAIL IN .env FILE

 DEPENDENCIES:-  pip install -r requirements.txt
